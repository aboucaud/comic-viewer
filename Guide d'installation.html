Installer le Kiosque BD

Le kiosque affiche une bande dessinée en plein écran : elle défile toute seule, et les visiteurs la feuillettent avec la souris. Comptez 10 minutes pour l'installer. Aucune connaissance en informatique n'est nécessaire.

Choisissez votre ordinateur :

WindowsPC portable ou de bureau. Rien à installer. MacGoogle Chrome nécessaire.

Ordinateur Windows 10 ou 11

Installation sous Windows

  1. Débloquez le fichier ZIP

    Vous avez reçu un fichier compressé (ZIP), par exemple kiosque-bd.zip. Avant de l'ouvrir :

    • faites un clic droit sur le fichier ZIP, puis Propriétés ;
    • tout en bas, cochez Débloquer, puis cliquez sur OK.

    Si la case « Débloquer » n'apparaît pas, passez simplement à l'étape suivante.

  2. Extrayez le dossier

    • Clic droit sur le fichier ZIP, puis Extraire tout…
    • Choisissez par exemple le dossier Documents, puis cliquez sur Extraire.

    Important : ne lancez pas le kiosque depuis l'intérieur du fichier ZIP. Utilisez toujours le dossier extrait.

  3. Placez votre BD dans le dossier

    Le dossier contient déjà une BD d'exemple nommée bd.pdf. Pour présenter la vôtre :

    • supprimez le fichier bd d'exemple ;
    • copiez votre PDF dans le dossier ;
    • renommez-le exactement bd : clic droit, Renommer.

    Windows cache souvent la fin « .pdf » des noms de fichiers. Si vous la voyez, le nom complet doit être bd.pdf. Si vous ne la voyez pas, tapez seulement bd.

  4. Mettez l'écran en portrait

    • Branchez l'écran de la borne.
    • Ouvrez Démarrer → Paramètres → Système → Écran.
    • Cliquez sur l'écran de la borne dans le schéma. Dans Orientation de l'affichage, choisissez Portrait.
    • Si plusieurs écrans sont branchés, cochez Faire de cet écran mon écran principal : le kiosque s'ouvre toujours sur l'écran principal.

  5. Lancez le kiosque

    Double-cliquez sur Lancer le kiosque - Windows. La BD apparaît en plein écran après quelques secondes.

    La première fois, Windows peut afficher un écran bleu « Windows a protégé votre ordinateur ». Cliquez sur Informations complémentaires, puis sur Exécuter quand même. Cela n'arrive qu'une fois.

  6. Préparez l'ordinateur pour l'exposition

    • Pas de mise en veille : Paramètres → Système → Alimentation (ou Alimentation et batterie), puis réglez l'écran et la mise en veille sur Jamais.
    • Pas de notifications : activez Ne pas déranger, en cliquant sur la cloche en bas à droite de l'écran.
    • Démarrage automatique (facultatif) : pour que le kiosque se lance à l'allumage de l'ordinateur,
      1. faites un clic droit sur Lancer le kiosque - Windows, puis Afficher d'autres options → Créer un raccourci ;
      2. appuyez sur ⊞ Windows + R, tapez shell:startup, puis Entrée ;
      3. déplacez le raccourci dans la fenêtre qui s'ouvre.

Mac · macOS 12 ou plus récent

Installation sur Mac

  1. Installez Google Chrome

    Safari ne sait pas afficher le kiosque en plein écran verrouillé. Si Chrome n'est pas déjà installé, téléchargez-le sur google.com/chrome.

  2. Extrayez le dossier

    Double-cliquez sur le fichier ZIP reçu : un dossier apparaît à côté. Rangez-le par exemple dans Documents.

  3. Placez votre BD dans le dossier

    Remplacez le fichier d'exemple bd.pdf par votre PDF, et donnez-lui exactement le même nom : bd.pdf.

  4. Lancez le kiosque une première fois

    Double-cliquez sur Lancer le kiosque - Mac.

    La première fois, macOS bloque le fichier, car il ne vient pas de l'App Store. Cliquez sur Terminé ou OK. Ouvrez ensuite Réglages Système → Confidentialité et sécurité, descendez en bas de la page et cliquez sur Ouvrir quand même. Confirmez avec votre mot de passe.
    Sur les versions plus anciennes de macOS, faites plutôt un clic droit sur le fichier, puis Ouvrir.

    Si une fenêtre propose d'installer les outils de ligne de commande, cliquez sur Installer. Attendez la fin (quelques minutes), puis double-cliquez à nouveau sur Lancer le kiosque - Mac.

    Une petite fenêtre « Terminal » s'ouvre en même temps que la BD. Laissez-la ouverte : c'est elle qui fait tourner le kiosque. Vous pouvez la réduire.

  5. Mettez l'écran en portrait

    • Réglages Système → Moniteurs, sélectionnez l'écran de la borne, puis Rotation : 90°.
    • Si plusieurs écrans sont branchés, faites de l'écran de la borne l'écran principal : dans Disposition…, glissez la barre blanche du haut sur cet écran.

  6. Préparez le Mac pour l'exposition

    • Pas de mise en veille : dans Réglages Système → Écran verrouillé, réglez la désactivation de l'écran sur Jamais.
    • Démarrage automatique (facultatif) : dans Réglages Système → Général → Ouverture, cliquez sur + et ajoutez Lancer le kiosque - Mac.

Windows et Mac

Pendant l'exposition

Au repos, la BD défile toute seule, en boucle. Un visiteur qui clique passe en lecture libre : il tourne les pages en cliquant sur les bords, avec la molette ou avec le menu jaune ☰ Chapitres.

  • Ctrl + Alt + QRemet la BD en défilement automatique. Maintenez Ctrl et Alt, puis appuyez sur Q.
  • Alt + F4Ferme le kiosque, sous Windows.
  • ⌘ Cmd + QFerme le kiosque, sur Mac.

Le clavier ne sert qu'au personnel : vous pouvez le ranger hors de portée du public. La souris suffit aux visiteurs.

Dépannage

En cas de problème

Ce que vous voyezQue faire
« Le kiosque ne trouve pas ses fichiers » ou « Fichiers du kiosque introuvables »Le kiosque a été lancé depuis le fichier ZIP. Extrayez d'abord le dossier (étape 2), puis lancez-le depuis le dossier extrait.
« La BD bd.pdf est introuvable »Vérifiez le nom de votre PDF (étape 3). Il ne doit pas s'appeler bd.pdf.pdf ni BD (1).pdf.
« Impossible d'ouvrir la BD »Le PDF est peut-être abîmé. Ouvrez-le avec votre lecteur PDF habituel pour vérifier, puis copiez-le à nouveau.
La BD s'ouvre sur le mauvais écranFaites de l'écran de la borne l'écran principal (étape « Mettez l'écran en portrait »), puis relancez.
La BD apparaît couchéeL'écran n'est pas en orientation portrait. Voir l'étape « Mettez l'écran en portrait ».
Windows : Alt + F4 ne ferme pas le kiosqueAppuyez sur Ctrl + Maj + Échap pour ouvrir le Gestionnaire des tâches. Cliquez sur Microsoft Edge (ou Google Chrome), puis sur Fin de tâche. Prévenez ensuite la personne qui vous a fourni le kiosque.
Le défilement est saccadéL'ordinateur est un peu lent pour cette BD. Prévenez la personne qui vous a fourni le kiosque : un réglage permet de passer en affichage page par page.

Pour obtenir de l'aide sous Windows, envoyez le fichier journal à la personne qui vous a fourni le kiosque. Appuyez sur ⊞ Windows + R, tapez %LOCALAPPDATA%\KiosqueBD, puis Entrée : le fichier s'appelle journal.txt.
